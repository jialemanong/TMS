# 深度组规则

## 一、基础概念
### 深度组定义
多个储位按深度排列组成的存储单元，用于密集存储场景，分为：
- **单向深度组**：每个储位只有1个深度值
- **双向深度组**：每个储位有2个深度值：L（上架方向深度）、R（下架方向深度）

### 三个核心标识
每个深度组维护：
| 标识 | 说明 | 0 | 1 |
|------|------|---|---|
| 空闲标识 | 深度L最小深度储位是否空闲 | 空闲 | 非空闲 |
| 上架标识 | 是否可分配上架任务 | 已分配上架任务 | 未分配（可用） |
| 下架标识 | 是否可分配下架任务 | 已分配下架任务 | 未分配（可用） |

### 混放控制
- 可按逻辑区设置：可混放 / 不可混放
- 不可混放时，无同批次可用深度组 → 提示"无可用库位"

## 二、单进单出模式
### 并发约束
同一深度组同一时间：**仅可分配1个上架任务 或 1个下架任务**（互斥）

### 上架分配逻辑
1. 筛选符合前置规则的空闲储位，对应到深度组
2. 筛选条件：空闲标识=0 且 上架标识=1
3. 排序优先级：
   - 第一优先级：相同批次深度组库存 由大→小（优先库存多的）
   - 第二优先级：库存相同 → 上架顺序 由小→大
   - 无相同批次且混放开启 → 上架顺序 由小→大
4. 命中深度组后分配具体储位：
   - 查询深度最小的有货储位
   - 不存在有货储位 → 深度由大→小排序，分配最大的
   - 存在有货储位（深度=a）→ 分配深度=a-1的储位
   - 深度相同 → 储位序号由小→大

### 下架分配逻辑
1. 找到符合的库存对应深度组
2. 筛选条件：下架标识=1
3. 排序优先级：
   - 第一优先级：深度组库存 由小→小（优先库存少的）
   - 第二优先级：库存相同 → 下架顺序 由小→大
4. 命中深度组后分配具体储位：
   - 深度由小→大排序，分配深度最小的库存

### 移库逻辑
移库上架分配逻辑与普通上架一致。

## 三、一侧进一侧出模式
### 并发约束
同一深度组同一时间：**可分配1个上架任务 + 1个下架任务**（并行，互不阻塞）
默认：L为上架方向，R为下架方向

### 上架分配逻辑
1. 筛选符合前置规则的空闲储位，对应到深度组
2. 筛选条件：空闲标识=0 且 上架标识=1
3. 排序优先级：
   - 相同批次深度组库存 由大→小
   - 库存相同 → 上架顺序 由小→大
   - 无相同批次且混放开启 → 上架顺序 由小→大
4. 命中深度组后分配具体储位：
   - 查询深度L最小的有货储位
   - 不存在 → 深度L由大→小排序，分配最大的
   - 存在（深度=a）→ 分配深度=a-1的储位

### 下架分配逻辑
1. 找到符合的库存对应深度组
2. 筛选条件：下架标识=1
3. 排序优先级：
   - 深度组库存 由小→小
   - 库存相同 → 下架顺序 由小→大
4. 命中深度组后分配具体储位：
   - 深度R由小→大排序，分配深度最小的库存

### 移库逻辑
移库上架分配逻辑与普通上架一致。

## 五、通用校验规则
所有深度组操作都需遵守：
1. 储位深度不可重复：同一深度组内同一深度值只能有一个储位
2. 创建储位时校验深度组编码+深度唯一性
3. 任务完成/取消后，必须释放对应上架/下架标识
4. 深度组按生成时间自动生成序号
5. 混放参数影响分配逻辑，需按逻辑区分配置
