# 取放货规则

## 一、放货规则（终点校验）
### 适用场景
- 点对点模式选择终点储位
- UI库位绑定操作
- 下料模式起点绑定
- 叫料模式终点校验
- 点对区/点搬运创建容器任务终点校验
- 点对区搬运创建容器任务终点校验

### 核心规则
#### 规则1：状态约束
- 可选择状态为**空闲**的储位

#### 规则2：深度组顺序约束
- 按照深度组上架顺序（深度L）由大到小分配
- 深度组中间有空闲/预占储位时，**不允许跳过**选择更深的储位
- 深度组中间有货阻挡时，**不允许跳过**占用储位选择里面的空闲储位

### 场景示例
#### 正常场景
深度组储位从外到内：1号（空）→ 2号（空）→ 3号（空）
- 优先分配最内侧3号（深度最大）
- 3号占了分配2号
- 2号占了分配1号

#### 阻挡场景
深度组储位：1号（空）→ 2号（有货）→ 3号（空）
- 不可跳过2号直接分配3号
- 只能分配1号，或先移库移走2号再分配3号

## 二、取货规则（起点校验）
### 适用场景
- 点对点/区模式选择起点储位
- UI库位解绑操作
- 点对区/点搬运创建容器任务起点校验
- 点对区UI下发任务起点校验

### 核心规则
#### 规则1：状态约束（模式1）
- 可选择储位状态为**占用**
- 无待处理的需求
- 无创建、待执行、执行中的任务

#### 规则2：状态约束（模式2）
- 可选择储位状态为**空闲 或 占用**
- 无待处理的需求
- 无创建、待执行、执行中的任务

### 核心约束
**同一储位同一时间只能有一个进行中的任务**
- 已有待处理需求 → 不可再选为起点
- 已有进行中任务（创建/待执行/执行中）→ 不可再选为起点

### 重复需求防护
- 移库场景：阻挡储位已有待处理需求或进行中任务 → 不重复生成移库需求
- 点对点场景：同储位已有同类型待处理需求 → 不重复入池

---

## 三、任务创建时双重校验
### 需求创建时
- 前端初步校验起点终点状态

### 容器任务生成时（资源变动触发）
- **再次校验**起点取货规则
- **再次校验**终点放货规则
- 校验不通过 → 不创建任务，需求保持待处理
- 防止需求入池后，储位状态发生变化导致任务创建失败

### 校验失败提示
- 起点问题："起点库位无货，请更换库位" / "该储位不可选择，请更换其他储位"
- 终点问题："终点库位非空闲，请更换库位" / "该储位不可选择，请更换其他储位"
- 深度组问题："起终点的选择不符合深度组规则，请更换库位"

---

## 四、储位绑定/解绑特殊规则
### 储位绑定（放货）
- 人工绑定容器到储位 → 储位置为占用
- 需符合放货规则校验
- 绑定信息记录：容器、储位、绑定时间

### 储位释放（解绑/取货）
- 人工解绑 → 储位置为空闲
- 清除容器绑定关系
- 需符合取货规则校验

### 带容器绑定
- 独立入口，权限控制
- 逻辑同普通绑定，直接指定容器+储位

## 五、测试重点校验清单
| 场景 | 校验项 |
|------|--------|
| 选终点 | 空闲状态校验、深度顺序、不可跳过阻挡 |
| 选起点 | 占用状态校验、无待处理需求、无进行中任务 |
| 任务生成 | 二次校验，状态变化后的正确性 |
| 多并发 | 同一储位不会被分配给多个任务 |
| 移库触发 | 阻挡判断正确，不重复生成需求 |
| 人工绑定解绑 | 状态变更正确，绑定关系记录准确 |
