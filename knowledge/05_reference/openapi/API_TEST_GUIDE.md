# TMS 接口自动化测试指南

## 一、文档与环境

- 文档入口：`http://111.160.91.170:59999/#/home`
- 网关地址：`http://111.160.91.170:59999`
- Swagger 版本：2.0
- 鉴权方式：请求头 `X-Access-Token`
- 原始规范：`raw/*.swagger.json`
- 接口明细：`generated/*.md`

环境账号、Token 获取方式、测试数据和数据库连接信息未包含在 Swagger 中，需由项目环境配置补充。

## 二、接口测试分层

| 层级 | 测试目标 | 典型断言 |
|---|---|---|
| 契约测试 | URL、方法、必填字段、字段类型 | HTTP 状态、参数校验、响应结构 |
| 业务测试 | 状态流转与资源变化 | 需求/任务状态、储位/容器绑定、日志 |
| 集成测试 | MES/WMS/RCS/设备交互 | 回调、幂等、超时、重试、外部日志 |
| 权限测试 | 登录、角色、数据权限 | 401/403、越权、数据隔离 |
| 稳定性测试 | 并发、重复请求、异常恢复 | 幂等、锁冲突、最终一致性 |

## 三、通用请求约定

1. 需要登录的接口携带 `X-Access-Token`。
2. `query`、`path`、`body`、`formData` 参数必须按明细中的“位置”发送。
3. 请求体模型名称可在同一服务明细的“数据模型”章节查询字段。
4. 上传接口的 Content-Type 以具体接口 Swagger 声明为准。
5. 分页接口除契约字段外，应覆盖空页、首页、末页、越界页和单页 500 条边界。

## 四、通用断言

每条接口用例至少覆盖：

- HTTP 状态与响应 Content-Type。
- 业务成功标识、业务码、消息文本和数据结构。
- 必填参数缺失、空值、非法类型、超长、非法枚举。
- 未登录、Token 失效、角色无权和跨数据范围访问。
- 重复提交、并发提交和请求重放。
- 操作前后数据库对象、状态机、资源占用及日志的一致性。

## 五、高风险接口保护

以下接口类别默认只允许在测试环境执行：

- `Test-Controller`、`test-modbus`。
- `tmsCase` 系统开关。
- 摄像头/雷达设备添加删除、报警灯控制。
- AGV、门、提升机、Modbus 等真实硬件控制。
- 批量删除、批量释放、任务取消和状态强制变更。

自动化框架应设置环境白名单，并对删除、硬件控制和系统开关增加二次保护。

## 六、业务链路组合

### 需求到任务

调用业务入口后，联合验证：

`需求生成 → 条件/规则匹配 → 容器任务 → 车辆任务 → RCS 下发 → 回调 → 完成/回滚`

### MES/WMS 入站

重点覆盖：

- 首次下发成功。
- 相同业务主键重复下发。
- 状态乱序、字段缺失、对象不存在。
- TMS 处理成功但回执失败。
- 外部系统超时、重试及日志留痕。

### AGV/设备回调

重点覆盖：

- 正常回调、重复回调、乱序回调。
- 未知任务号、已取消任务、已完成任务。
- 设备离线、超时、异常码。
- 回调后任务、储位、容器和管制资源的一致性。

## 七、已知文档缺口

- Swagger 未提供统一业务错误码表。
- 是否免鉴权、Token 获取方式及权限范围未明确。
- 部分接口描述含 `TEST` 或命名不规范，不能据此判断生产可用性。
- 外部系统签名、重试、超时和幂等键规则未完整声明。
- 性能指标与并发上限未声明。

这些信息不能自行推断；发现后应补入约束规则或测试反馈目录。
