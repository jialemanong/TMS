# 上下游系统交互规则

## 一、上游系统通信

### 1.1 明眸（激光检测）通信
#### 有货信号（无货→有货）
- 触发：人工放置托盘，明眸检测到状态变更
- 传输参数：储位、货型
- TMS处理逻辑：
  1. 创建容器（无容器号场景自动生成ID+编码）
  2. 容器与当前储位绑定
  3. 储位置为【占用】状态
  4. 校验是否满足需求池记录条件，满足则写入需求池
- 重复触发防护：储位状态非空闲时再次收到有货信号，不重复处理

#### 无货信号（有货→无货）
- 触发：人工取走托盘，明眸检测到状态变更
- 传输参数：储位
- TMS处理逻辑：
  1. 校验：储位为占用状态 且 无待处理需求
  2. 满足条件则记录至需求池
  3. 解除容器与储位绑定
- 重复触发防护：储位状态非占用时再次收到无货信号，不重复处理

### 1.2 雷达通信
#### 取走检测（有货→无货）
- 触发：雷达检测到托盘被取走
- TMS处理逻辑：
  校验储位为占用 且 无进行中任务（创建/待执行/执行中），满足则记录至需求池

### 1.3 WMS通信
- 下发搬运任务：传起点+终点 / 起点+终点库区
- 携带容器号时，使用外部容器号创建容器
- 所有WMS下发需求均记录需求池

### 1.4 MES通信
- 下发工单、工序、工艺路线数据
- 触发上料（叫料）、下料需求
- 所有MES触发需求均记录需求池

## 二、下游系统通信

### 2.1 RCS（机器人调度系统）
#### 任务下发
- 容器任务分配车辆后，调用RCS接口下发搬运任务
- 任务状态实时同步

#### 管制区管理
- AGV进入管制区前，向TMS发送进入请求
- TMS记录：请求ID、车辆ID、管制区ID、状态（请求进入→已进入→已退出）
- TMS校验通过后回告授权进入
- TMS轮询AGV退出状态，退出后更新状态

#### 异常回告
- AGV到达起点发现无货 → 回告异常，TMS记录任务异常
- AGV到达终点发现有货 → 回告异常，TMS记录任务异常
- RCS手动取消任务 → TMS任务置为取消，释放预占资源，需求回退为待处理
- RCS手动完成任务 → TMS任务置为完成，执行对应状态动作

### 2.2 自动门控制系统
#### 对应关系
- 数据库维护管制区与门的对应关系（管制区ID、门IP、门状态）

#### 请求开门流程
- 检测到管制区有待授权AGV → TMS持续请求开门
- 门开门到位后 → 授权AGV进入管制区

#### 请求关门流程
- 检测到管制区内所有AGV均已退出 → TMS请求关门
- 门关闭后更新状态

#### 门状态维持规则
1. 无待授权、无已授权AGV + 门关闭 → 无操作
2. 无待授权、无已授权AGV + 门开启 → 执行关门
3. 有待授权、无已授权 → 开门，到位后授权
4. 无待授权、有已授权 → 持续开门（1秒/次，可配置）
5. 有待授权、有已授权 → 开门+授权+持续开门

### 2.3 电梯控制系统
- 每个任务类型对应独立封装算法（项目定制）
- 起点为电梯储位：任务状态【已离开】→ 通知释放电梯
- 终点为电梯储位：任务状态【已完成】→ 通知释放电梯

### 2.4 广播系统
- 满足操作型规则配置条件时，触发对应广播语音通知

## 三、异常处理规则
### 外部信号异常
当前储位存在进行中任务时，无论收到有货/无货信号：
- 储位状态不做变动
- 信号标记为异常信号，关联记录到对应任务

### AGV回告异常
- 起点无货异常：记录任务异常日志
- 终点有货异常：记录任务异常日志
- 所有异常信息留存于任务关联异常记录中
