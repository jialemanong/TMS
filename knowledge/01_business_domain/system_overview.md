# TMS系统整体架构总览

## 一、系统定位
本TMS为**工厂内部AGV搬运调度管理系统**，负责仓储与生产车间之间的物料自动搬运调度，对接上游MES/WMS/明眸检测系统，下游调度RCS机器人控制系统、自动门、电梯、广播等硬件设备。

核心能力：需求接收 → 规则匹配 → 任务生成 → 车辆调度 → AGV执行 → 状态回传全链路管理。

## 二、系统模块划分
### 1. 后台管理端
- 权限管理：用户、角色、菜单（含PAD端、PDA端、广播端）
- 基础数据：仓库、储区、储位、逻辑区、容器、路由、车辆、货型、工序
- 工单管理：工单、流程卡、工艺路线
- 规则引擎：状态动作、条件组、规则、任务组、操作型规则
- 任务池：需求池、容器任务池、车辆任务池
- 参数配置、报表、AGV异常管理

### 2. 服务端核心逻辑
- 模式管理：点对点搬运、移库、点对区搬运
- 深度组规则引擎：单进单出、一侧进一侧出、双进双出
- 任务组逻辑：横拆（同车多任务）、纵拆（多段路径组合）
- 上下架/取放货规则
- 容器创建与绑定逻辑
- 资源池管理：电梯、车辆
- 第三方系统通信网关

### 3. 终端页面
- **PAD端**：叫料、下料、点对点搬运、点对区搬运、储位绑定/释放、任务列表、容器列表、需求池列表
- **PDA端**：库位绑定/解绑、点对区搬运、任务查询、需求池查询

## 三、系统交互边界
### 上游系统（输入）
| 系统 | 交互内容 |
|------|----------|
| MES | 下发工单、工序信息、叫料/下料触发 |
| WMS | 下发搬运任务、容器信息 |
| 明眸（激光检测） | 储位有货/无货状态检测信号 |
| 雷达 | 储位取走检测信号 |
| 按钮硬件 | 手动触发搬运需求 |

### 下游系统（输出）
| 系统 | 交互内容 |
|------|----------|
| RCS（机器人调度系统） | 下发AGV搬运任务、管制区授权 |
| 自动门控制系统 | 请求开门、关门指令 |
| 电梯控制系统 | 电梯占用、释放通知 |
| 广播系统 | 语音广播通知 |

## 四、核心业务对象关系
```
工单 → 工艺路线 → 多道工序
工序 → 流程卡 → 容器（托盘）
储位 → 归属储区 → 归属仓库
储位 → 绑定深度组
容器 → 可绑定储位（起点/终点）
需求 → 匹配条件组+规则 → 生成容器任务
容器任务 → 调度车辆 → 生成车辆任务 → 下发RCS
任务组 → 包含多个子任务（横拆/纵拆）
```

## 五、核心业务模式
1. **点对点搬运**：指定起点储位 → 终点储位，AGV直接搬运
2. **点对区搬运**：指定起点储位 → 终点逻辑区，系统自动分配区内具体储位
3. **叫料（上料）**：生产工位呼叫物料从缓存区搬运到工位
4. **下料**：生产完成后物料从工位搬运到缓存区
5. **移库**：深度组内因阻挡自动触发的库位调整
6. **自动搬运**：满足规则条件后系统自动触发的搬运需求

## 六、全局通用规则

- 分页单页最大数据量：500条
- 日志自动定期清理（每月一次）
